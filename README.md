# 周易研习 · 微信小程序

周易哲学学习工具 + 六爻铜钱卜卦练习。先明易理，再识象数，后学排盘断事。

## 打开方式

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 选择「导入项目」，目录选本文件夹 `liuyao-miniprogram`
3. AppID 已写入：`wx2a67beceaff79138`
4. 点击编译即可预览

无需先在开发者工具里「新建」——本目录已是完整原生小程序工程。

浏览器预览：打开 `preview/liuyao-standalone.html`，或运行 `preview/` 下静态服务。

### 预览同步与校验

发布网页或手机预览前先运行：

```sh
node scripts/verify-preview-assets.mjs
node scripts/prepare-web-preview.mjs /path/to/site/public
```

同步工具会连同字体、品牌图和铜钱图片一起复制；资源缺失或罗盘权限逻辑异常时，
校验会直接失败。小程序原生页面与独立网页预览应在同一批修改中一起更新，再统一
部署，避免重复发布。

## 功能

- **研习**：八卷教材——开宗 → 易理 → 象数 → 卜卦 → 排盘 → 断卦 → 梅花 → 附录（类象/纳甲全表/口诀/卦例；由理入术）
- **卜卦**：三钱摇爻，字阳背阴，六次成卦
- **梅花**：报数 / 时间（农历年月日时）/ 随机起卦，体用生克，本·互·变
- **排卦**：本卦 / 变卦、世应、六亲、六神、纳甲
- **干支历**：年月日柱（按交节时刻推算）、旬空、月令旺衰；临近交节自动提示复核
- **伏神**：用神不现时取本宫伏藏
- **断卦**：取用神 / 元神、空亡、旺衰、动化生克提示（教学演示）
- **历史**：本地保存最近卦例（六爻与梅花）
- **账户**：首次微信登录自动注册本机账户，支持会话恢复、资料编辑、退出与注销；临时 code 不落盘

**改代码前先打开** [CODE_INDEX.md](CODE_INDEX.md)：一句话定位表 · 问题速查 · utils API 地图 · 存储 key · 预览同步 · 终端 `rg` 命令。

## 说明

- 定位为学习与推演练习，而非替代个人抉择的「算命」。
- 干支月柱按节气时刻公式推算；若距交节约三小时内会明确提示用专业万年历复核，避免边界时刻悄悄判错月柱。
- 断语为传统规则化提示，供学习参考，不作绝对吉凶承诺。
- 第一版账户资料与历史卦例仅保存在当前设备，退出登录不会删除；卸载或清理微信存储后可能丢失。
- 当前没有服务端，故不能跨设备识别同一用户。正式云端账户必须把 `wx.login` 临时 code 立即提交开发者服务端换取 `openid/session`；本项目不会在客户端保存 code 或 `session_key`。
- 本项目与 RiverLens 业务无关，建议拷贝到单独仓库维护。
